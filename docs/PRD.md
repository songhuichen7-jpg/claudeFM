# Claudio FM — PRD

> 私人 AI 电台。一个会读你品味、会主持的 DJ（Claudio），既是播放器也是聊天界面。
> 本文件是 MVP 范围与验收的"宪法"。改需求先改这里，再进 `TODO.md`。

## 1. 定位 / 用户 / 痛点

- **用户**：veko 一个人（单听众电台）。
- **痛点**：算法推荐没有"人"，歌单按曲风分而不是按"我此刻的状态"分；想要一个懂我品味、会说话、能随时点歌的私人主播。
- **一句话**：`Your mood is my prompt. I hate algorithm. I have taste.`

## 2. 当前里程碑：把真实应用对齐到 `prototype/`

这一轮**不是新功能**，是**让真实前端 `src/` 完全对齐已批准的 `prototype/` 设计与交互**，保留真实后端链路，端到端调通 + E2E。

- 设计语言以 `prototype/` 为唯一事实源（终端 × 编辑感，见 `DESIGN.md`）。
- 后端 `server/` 维持现状，仅允许**小幅新增**（如 `GET /api/liked`），不改既有契约。

## 3. 核心用户旅程（E2E 用例直接由此翻译）

1. **开机即播报**：打开页面 → Claudio 自动来一段开场口播（DJ turn），并把推荐的第一首歌设为当前曲目。
2. **对话点歌**：在底部输入框说话 →
   - 说"放一首 X" → Claudio 回应并**播放指定歌**（NCM 解析）。
   - 说心情/场景 → Claudio 回应并推荐一首，进聊天流。
3. **播放控制**：播放/暂停、上一首、下一首、停止、音量、喜欢（♥）。下一首会让 Claudio 出一段过渡。
4. **喜欢即学品味**：点 ♥ → 底部浮 toast「记进了你的品味」；顶栏 `♥ N` 计数 +1；Library 里能看到这首。
5. **Library**：点顶栏 `♥ N` → 看到所有喜欢过的歌，可播放、可取消喜欢。
6. **Focus 沉浸视图**：点时钟面板 → 全屏白卡浮在星空背景上，大歌名 + 逐字高亮的 DJ 口播转录。
7. **Settings**：点齿轮 → 服务器状态 / 语料档(profile) / 今日编排(schedule) / 网易云账号 / 品味语料编辑。
8. **主题**：DARK / LIGHT 切换，全站生效并持久化。

## 4. MVP 功能清单（对齐目标）

- [ ] 单列布局：Header → 时钟面板 → 播放条 → 聊天流 → 输入框 → footer，外加居中"设备框"+ 边缘辉光。
- [ ] Header：像素字标 Claudio + `♥ N`(Library) + 齿轮(Settings) + DARK/LIGHT。
- [ ] 时钟面板：点阵网格 + 像素大钟 + ON AIR。点击进 Focus。
- [ ] 播放条：EQ 字形 + 曲目 + 传输键(prev/play/next/stop/♥) + HIDE/FAV/VOL + 进度 + QUEUE 计数。
- [ ] 聊天流：等宽发丝气泡，▸ 曲目卡（可播放/可♥），逐字高亮，REPLAY。
- [ ] 输入框：点歌/对话，聚焦时单绿描边。
- [ ] Focus：白卡 over 星空 + 波形 + 大歌名 + 转录。
- [ ] Library：喜欢曲目列表（真实，跨会话）。
- [ ] Settings：状态/语料档/今日编排/网易云/品味语料，全等宽单绿语言。
- [ ] Toast：♥ 反馈。
- [ ] Profile 卡：点头像，Claudio 主页（像素风、流派标签）。

## 5. 绝对不做（黑名单）

- ❌ 不做多用户 / 账号体系（永远单听众）。
- ❌ 不做 mood 选择器 / 黑胶旋转封面 / 紫色渐变 / 双栏 Spotify 布局（这些是走过的弯路，已废弃）。
- ❌ 不做"从汽水音乐导入"入口（品味只走网易云；`/api/taste/analyze` 端点保留但 UI 不暴露）。
- ❌ 不动后端既有契约（只允许新增，不改不删）。
- ❌ 不引入新的设计语言；偏离 `prototype/` 一律以 `prototype/` 为准。

## 6. 验收标准

- 真实 `src/` 视觉与交互与 `prototype/` 一致（暗/亮、桌面/移动）。
- `pnpm dev` 起真实 server+web，第 3 节 8 条旅程全部跑通。
- `tests/e2e/` Playwright 覆盖核心旅程，全绿。
- `pnpm build` 通过；不破坏 `server/`、`PlayerContext` 的既有逻辑（见 `ARCHITECTURE.md` 禁止破坏清单）。
